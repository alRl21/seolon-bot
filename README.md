# 설온지기

## 운영 시간

한국 시간 07:00~24:00에만 실행됩니다. Railway cron은 UTC 기준 `0 22 * * *`입니다.
자정에는 Discord 연결을 닫고 프로세스를 종료합니다. 00:00~07:00에 재배포되어도 봇은 접속하지 않습니다.
자동 재시작 정책은 NEVER로 설정해 자정 종료 후 다시 켜지지 않게 합니다.
오전 7시 시작은 Railway 예약 실행 특성상 수분 지연될 수 있습니다.
낮에 프로세스가 비정상 종료되면 다음 예약 실행까지 기다리거나 수동 재배포가 필요합니다.
새벽에도 저장 공간 및 요금제 기본 비용은 남을 수 있습니다.

설온 서버 전용 채널 디자인·출석 봇. 현재 온라인 실행 환경 연결 전입니다.

## 명령어

| 명령어 | 기능 |
| --- | --- |
| `/디자인` | 변경 내용을 미리 본 뒤 버튼으로 적용 |
| `/출석` | 한국 시간 기준 하루 1회 눈꽃 지급 |
| `/여권` | 누적 출석과 잔액 확인 |
| `/상태` | 구현된 기능 확인 |
| `/구조기록` | 채널 이름과 위치 기록 다운로드 |

모든 명령어와 적용 버튼은 코드에 지정된 소유자만 사용합니다.
다른 관리자도 실행할 수 없습니다. 출석 역시 현재는 소유자 테스트용입니다.
AI 대화·회원 제재·자동 음성방·상점 교환·역할 자동 지급은 아직 없습니다.

## 온라인 실행

Dockerfile과 railway.toml이 저장소 최상단에 포함되어 있습니다.
Railway에서 GitHub 저장소를 연결하고 다음을 설정합니다.

1. 서비스 Variables에 `DISCORD_TOKEN`을 추가하고 실제 봇 토큰을 값으로 입력합니다.
2. 영구 Volume을 서비스에 연결하고 Mount Path를 `/data`로 지정합니다.
3. 배포합니다. `DATA_DIR=/data`는 Dockerfile에 이미 설정되어 있습니다.
4. 로그에 `설온지기 연결 완료`가 표시되는지 확인합니다.
5. 설온 서버에서 지정된 소유자가 `/상태`, `/디자인` 순서로 확인합니다.

토큰은 GitHub 파일·이슈·커밋·ChatGPT 대화에 입력하지 않습니다.
현재 지정된 봇의 토큰인지 시작 시 확인합니다.
이 봇은 웹사이트가 아니므로 도메인 생성이나 HTTP 상태검사 경로는 필요하지 않습니다.
하나의 봇 프로세스만 실행하세요. 영구 저장 없이 재배포하면 잔액과 기록이 사라질 수 있습니다.
호스팅 요금과 무료 체험의 네트워크 제한은 서비스에서 확인해야 합니다.

## 디자인 범위

기존 카테고리와 채널의 알려진 이름을 찾아 이름을 변경하고, 없는 항목만 추가합니다.
후보가 중복되면 추측하지 않고 중단합니다. 기존 메시지와 채널을 삭제하지 않습니다.
기존 접근 권한과 기존 채널 순서는 유지합니다.
음성방과 운영진 전용 공간은 아직 변경하지 않습니다.
전체 서버 재정렬·자동 복원 기능은 없습니다.
